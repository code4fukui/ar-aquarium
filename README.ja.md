# ar-aquarium

ウェブブラウザ上でアニメーションする魚を表示する、拡張現実（AR）水族館シミュレーションアプリです。

## デモ
https://code4fukui.github.io/ar-aquarium/

## 機能
- アニメーションする魚が泳ぐ水族館を表示
- 魚のデータをCSVまたはJSONファイルから読み込み可能
- 魚のサイズ、波の周波数、振幅、速度のカスタマイズに対応
- 魚の初期表示数と更新間隔（リフレッシュレート）の制御が可能

## データ
魚のデータはCSVまたはJSONファイルに保存され、以下のフィールドを持ちます。

- `file`: 画像のファイル名
- `size`: 魚の幅
- `freq`: 波の周波数
- `amp`: 波の振幅
- `speed`: 魚の速度
- `enabled`: 魚の表示/非表示（1で有効、0で無効）

## 使い方
アプリケーションを実行するには、ウェブブラウザで `index.html` を開きます。URLにパラメータを渡すことで、アプリケーションをカスタマイズできます。

- `url`: 魚のデータファイル（CSVまたはJSON）のURL。デフォルトは `./fishes.csv`
- `nfishes`: 魚の初期表示数。デフォルトは `30`
- `dtrefresh`: 更新間隔（秒単位）。デフォルトは `0`（更新なし）
